TR Folder Extractor
This Python app extracts folders containing "tr" from RAR and ZIP archives. It supports password-protected files using a list of passwords and provides a Tkinter-based graphical user interface (GUI) for easy interaction.

Features:
RAR/ZIP Support: Extracts from both RAR and ZIP files.

Password List: Uses a list of passwords to attempt extraction for protected archives.

TR Folder Extraction: Identifies and extracts folders containing "tr" in their names.

Progress Monitoring: Displays progress and allows cancellation of the extraction process.

Auto WinRAR Detection: Automatically locates WinRAR for RAR extractions.

How to Use:
Select the archive and password list.

Click "Start Extraction" to attempt extracting the folder.

View progress and results in the app's interface.

Requirements:
Python 3.x

WinRAR for RAR extractions
